# github-upload

> 一键将本地项目推送到 GitHub 的 Codex 技能（双语 README + PAT 记忆）
> One-click push local projects to GitHub (bilingual README + PAT persistence)

---

## 中文介绍

### 是什么
github-upload 将本地文件夹/zip 一键推送到 GitHub，自动生成中英双语 README/LICENSE 并可记忆 PAT，下次免输入。

### 触发 / 使用
按 SKILL.md 指引使用，Codex 自动加载。

### 核心功能
- 见项目文件

### 安装
```powershell
双击 install.cmd 或 powershell -ExecutionPolicy Bypass -File install.ps1
```

### 目录结构
```
push-github-upload/
├── .gitignore
├── README.md
├── references
│   ├── readme-guide.md
│   ├── readme-template.md
│   └── token-setup.md
├── scripts
│   └── github_upload.py
└── SKILL.md
```
